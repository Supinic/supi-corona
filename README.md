# supi-corona
Cron scraper/fetcher of COVID-19 virus stats from various sources across the globe

Project retired in January 2024, where the consumer of these stats ([Supibot](//github.com/supinic/supibot) command `$corona` or `$covid`) was reworked so it only posts simple statistics rather than various level of detailed stats.

For more info, see the [commit details](https://github.com/Supinic/supibot/commit/5d9bbb694191401af712ebbd9bd7738529fc0fa0).

The service was then stopped, and later archived in May 2026.
